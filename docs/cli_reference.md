# ⚙️ CLI Reference

Complete reference for PowerScript command-line tools.

---

## 📦 Available Commands

TPS provides 4 main CLI commands:

| Command | Purpose | Status |
|---------|---------|--------|
| `tps-compile` | Compile `.ps` to `.py` | ✅ Stable |
| `tps-run` | Compile and execute | ✅ Stable |
| `tps-create` | Create new projects | ✅ Stable |
| `tps-check` | Type check without compiling | ✅ Stable |

## 🔧 tps-compile

Compile PowerScript files to Python.

### Basic Usage

```bash
# Compile single file
tps-compile myfile.ps

# Output: myfile.py
```

### Options

```bash
tps-compile [OPTIONS] <input_file>
```

| Option | Description | Default |
|--------|-------------|---------|
| `-o, --output <file>` | Output file path | `<input>.py` |
| `-d, --output-dir <dir>` | Output directory | Current dir |
| `--strict` | Enable strict type checking | `false` |
| `--no-runtime` | Exclude runtime imports | `false` |
| `-v, --verbose` | Verbose output | `false` |
| `-q, --quiet` | Suppress output | `false` |
| `--help` | Show help message | - |
| `--version` | Show version | - |

### Examples

**Custom Output:**
```bash
tps-compile main.ps -o build/main.py
```

**Output Directory:**
```bash
tps-compile src/app.ps -d build/
# Creates: build/app.py
```

**Strict Mode:**
```bash
tps-compile app.ps --strict
# Enables strict type checking
```

**Verbose Compilation:**
```bash
tps-compile app.ps -v
# Shows detailed compilation steps
```

**Quiet Mode:**
```bash
tps-compile app.ps -q
# No output unless errors
```

### Exit Codes

| Code | Meaning |
|------|---------|
| `0` | Success |
| `1` | Compilation error |
| `2` | File not found |
| `3` | Invalid options |

### Output Format

Compiled Python includes:

```python
#!/usr/bin/env python3
# Generated by PowerScript Compiler v1.0.0
# Source: app.ps

from powerscript.runtime import Console
# ... imports

# Your compiled code here
```

## 🚀 tps-run

Compile and execute PowerScript files immediately.

### Basic Usage

```bash
tps-run myfile.ps
# Compiles and runs in one step
```

### Options

```bash
tps-run [OPTIONS] <input_file> [-- <args>]
```

| Option | Description | Default |
|--------|-------------|---------|
| `--no-cache` | Don't cache compiled output | `false` |
| `--keep` | Keep compiled `.py` file | `false` |
| `--strict` | Enable strict type checking | `false` |
| `-v, --verbose` | Verbose output | `false` |
| `-q, --quiet` | Suppress compilation output | `false` |
| `--help` | Show help message | - |
| `--version` | Show version | - |

### Examples

**Run with Arguments:**
```bash
tps-run script.ps -- arg1 arg2 arg3
```

**Keep Compiled File:**
```bash
tps-run app.ps --keep
# Keeps app.py after execution
```

**No Cache:**
```bash
tps-run app.ps --no-cache
# Force recompilation
```

**Verbose Run:**
```bash
tps-run app.ps -v
# Shows compilation + execution output
```

### How It Works

1. Compiles `.ps` to `.py` (in memory or temp file)
2. Executes Python code
3. Cleans up temp files (unless `--keep`)

### Exit Codes

| Code | Meaning |
|------|---------|
| `0` | Success |
| `1` | Compilation error |
| `2` | Runtime error |
| `3` | File not found |

## 🏗️ tps-create

Create new PowerScript projects with boilerplate.

### Basic Usage

```bash
tps-create my-project
cd my-project
```

### Options

```bash
tps-create [OPTIONS] <project_name>
```

| Option | Description | Default |
|--------|-------------|---------|
| `-t, --template <name>` | Project template | `basic` |
| `--no-git` | Don't initialize git | `false` |
| `--no-venv` | Don't create virtual env | `false` |
| `-f, --force` | Overwrite existing | `false` |
| `--help` | Show help message | - |

### Templates

#### `basic` (Default)

Simple project with one file:

```
my-project/
├── src/
│   └── main.ps
├── build/
├── powerscript.toml
└── README.md
```

**main.ps:**
```powerscript
function main(): void {
    console.log("Hello from PowerScript!");
}
```

#### `class` Template

Object-oriented project:

```
my-project/
├── src/
│   ├── main.ps
│   └── models/
│       └── example.ps
├── build/
├── powerscript.toml
└── README.md
```

#### `web` Template

Web application structure:

```
my-project/
├── src/
│   ├── app.ps
│   ├── routes/
│   └── models/
├── static/
├── templates/
├── build/
├── powerscript.toml
└── README.md
```

### Examples

**Basic Project:**
```bash
tps-create my-app
```

**Class-based Project:**
```bash
tps-create my-app -t class
```

**Web Application:**
```bash
tps-create my-web-app -t web
```

**No Git Init:**
```bash
tps-create my-app --no-git
```

**Force Overwrite:**
```bash
tps-create my-app -f
```

### Generated Files

**powerscript.toml:**
```toml
[project]
name = "my-project"
version = "0.1.0"
entry = "src/main.ps"
author = ""

[compiler]
output_dir = "build"
strict_types = true
target_version = "3.9"

[runtime]
include_builtins = true
```

## ✅ tps-check

Type check PowerScript files without compiling.

### Basic Usage

```bash
tps-check myfile.ps
# Validates types only
```

### Options

```bash
tps-check [OPTIONS] <input_file>
```

| Option | Description | Default |
|--------|-------------|---------|
| `--strict` | Strict type checking | `false` |
| `--warnings` | Show warnings | `true` |
| `--json` | JSON output | `false` |
| `-v, --verbose` | Verbose output | `false` |
| `--help` | Show help message | - |

### Examples

**Basic Check:**
```bash
tps-check app.ps
# Type checks app.ps
```

**Strict Mode:**
```bash
tps-check app.ps --strict
# Strict type validation
```

**JSON Output:**
```bash
tps-check app.ps --json
# Outputs results as JSON
```

### Output Format

**Success:**
```
✓ Type check passed: app.ps
  No issues found.
```

**With Errors:**
```
✗ Type check failed: app.ps

Line 5: Type mismatch
  Expected: number
  Got: string
  
Line 12: Undefined variable 'x'
  
2 errors found.
```

**JSON Output:**
```json
{
  "file": "app.ps",
  "status": "error",
  "errors": [
    {
      "line": 5,
      "column": 10,
      "message": "Type mismatch",
      "expected": "number",
      "got": "string"
    }
  ],
  "warnings": []
}
```

### Exit Codes

| Code | Meaning |
|------|---------|
| `0` | No errors |
| `1` | Type errors found |
| `2` | File not found |

## 📁 Configuration Files

### powerscript.toml

Project-level configuration:

```toml
[project]
name = "my-project"
version = "1.0.0"
entry = "src/main.ps"
author = "Your Name"
license = "MIT"

[compiler]
output_dir = "build"
strict_types = true
target_version = "3.9"
optimize = true

[runtime]
include_builtins = true
async_enabled = true

[paths]
source = "src"
build = "build"
tests = "tests"
```

### .powerscriptignore

Exclude files from compilation:

```gitignore
# Ignore patterns
*.test.ps
tests/
node_modules/
__pycache__/
*.pyc
```

## 🔗 Command Chaining

### Build Pipeline

```bash
# Type check → Compile → Run
tps-check app.ps && tps-compile app.ps && python app.py
```

### Watch Mode (with external tool)

```bash
# Install nodemon
npm install -g nodemon

# Auto-compile on changes
nodemon --watch src --ext ps --exec "tps-compile src/main.ps"
```

### Batch Compilation

```bash
# Compile all .ps files in directory
for file in src/*.ps; do
    tps-compile "$file" -d build/
done
```

## 🎯 Best Practices

### Development Workflow

```bash
# 1. Type check first
tps-check src/main.ps

# 2. Compile if no errors
tps-compile src/main.ps -d build/

# 3. Run compiled code
python build/main.py
```

### Production Build

```bash
# Strict type checking + optimized build
tps-compile src/main.ps \
    --strict \
    --output-dir dist/ \
    --no-runtime
```

### Testing

```bash
# Check all test files
for file in tests/*.ps; do
    tps-check "$file" || exit 1
done
```

## 📊 Performance Tips

1. **Use `--no-cache` sparingly** - Caching speeds up repeated runs
2. **Compile once, run many** - Prefer `tps-compile` for repeated execution
3. **Batch operations** - Compile multiple files in one command
4. **Type check early** - Catch errors before compilation

## 🆘 Troubleshooting

### Command Not Found

```bash
# Check installation
pip list | grep tps

# Reinstall if missing
pip install --force-reinstall tps
```

### Permission Denied

```bash
# On macOS/Linux, make scripts executable
chmod +x $(which tps-compile)
```

### Import Errors

```bash
# Ensure TPS installed
python -c "import powerscript; print(powerscript.__version__)"
```
