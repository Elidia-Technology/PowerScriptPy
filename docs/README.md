## 📝 Quick Reference Card

### Installation
```bash
pip install tps
```

### Hello World
```powerscript
function main(): void {
    console.log("Hello, PowerScript!");
}
```

### Compile & Run
```bash
tps-compile hello.ps
python hello.py
```

### Quick Run
```bash
tps-run hello.ps
```

### Create Project
```bash
tps-create my-project
```

### Type Check
```bash
tps-check hello.ps
```
